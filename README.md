# Student Record Management System

## About the Project
This is a beginner-friendly C++ console application designed to manage student academic records.

## Features
- Add new student details
- Display all student records
- Search students using roll numbers
- Calculate average marks

## Technologies Used
- C++
- Object-Oriented Programming
- Arrays and Functions
- Conditional Statements and Loops

## How to Run
1. Open an online C++ compiler.
2. Copy the code from `main.cpp`.
3. Paste it into the compiler.
4. Click Run and select the required menu option.

## Learning Outcome
Through this project, I learned how to use classes, objects, arrays, functions and loops to develop a simple real-world application.
